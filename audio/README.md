# Sound library for Mawaqit Home

Files in `audio/adhan/` and `audio/dua/` are offered inside the app (listed in MainActivity: ADHAN_CATALOG / DUA_CATALOG).
When the user picks one it is downloaded once to the device and then plays offline.
To add a sound: upload the file here and add a line to the catalogue.
Only upload recordings you have the right to redistribute - this repository is public.
