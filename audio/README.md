# Sound library for Mawaqit Home

Put audio files here (mp3 / ogg / m4a / wav). The app lists them live from GitHub:

- `audio/adhan/` — adhan recordings (e.g. `Makkah_Adhan.mp3`)
- `audio/dua/`   — du'a after the adhan

Name the file the way you want it shown in the app (`_` and `-` become spaces).
Only upload recordings you have the right to redistribute — this repository is public.
